# Historical exploratory scripts

These are the original `01_explore.py` through `04_fix.py` files. They are preserved as development history, not as the supported monitoring workflow.

They expect `reviews_raw.csv` in the current working directory and require pandas. Their historical cutoffs and theme rules differ from the current pipeline. Some early patterns are broad or incomplete. Their printed results should not be mixed with current rolling-year results.

For collection, classification and reporting, use `Pull_reviews.py` at the repository root. Pandas is not required by that entry point.
